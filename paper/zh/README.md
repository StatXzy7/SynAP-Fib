# SynAP-Fib 中文稿

当前中文修改入口是 [main.tex](main.tex)。英文稿位于 [../en/main.tex](../en/main.tex)，图片与参考文献在 `../en/`，由两份稿件共享。

原稿声明仍保留：中文稿仅供作者参考和修改，不用于投稿；中英文不一致时以英文主稿为准。目录整理没有改变此声明。

在本目录运行 `latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex`，或从仓库根目录使用 `tools/build_paper.ps1` 编译全部稿件。修改后同步中英文的表格数值、方法和结论限定语。
